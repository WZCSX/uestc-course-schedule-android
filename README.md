# 安卓 APK 工程

这是“研一课程表”的原生安卓应用，课程数据完全保存在手机本地，不连接学校网站。

## 上课提醒

- 默认在上课前 15 分钟发送包含课程名称、时间和地点的通知。
- 可在设置中改为提前 5、10、15 或 30 分钟，也可关闭提醒。
- 使用安卓闹钟机制，App 关闭或锁屏后仍能提醒；手机重启后自动恢复。
- 课程表页面支持“单日”和“七日”两种查看模式。

## 桌面小组件

- 4×3 桌面小组件显示当天日期、课程名称、时间与地点。
- 点击小组件可打开 App，到午夜会自动切换为新一天的课程。
- 编辑课程或上课时间后，小组件会同步更新。
- 3.1.1 修复部分安卓桌面提示“小组件无法加载”的兼容性问题。

## 课表文件

- 导出会打开安卓系统保存窗口，生成可分享的 JSON 课表文件。
- 导入会打开安卓系统文件选择器；确认后替换课程与上课时间。
- 导入成功后自动重建上课提醒并刷新桌面小组件。

## 构建

需要 Android SDK 35、JDK 17 和 Gradle 8.11.1。在本目录运行：

```bash
gradle assembleDebug
```

生成文件：`app/build/outputs/apk/debug/app-debug.apk`。

也可以将本目录推送至 GitHub，仓库自带的 Actions 工作流会生成可下载 APK。
