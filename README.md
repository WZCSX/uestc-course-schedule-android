# 安卓 APK 工程

这是“研一课程表”的原生安卓壳工程，课程修改保存在手机本地。2.1 版增加了“云中成电”首页日程识别。

## 学校自动同步

- 首次在“设置—学校课表同步”中登录电子科技大学统一身份认证。
- 登录后停留在“云中成电”首页即可，App 会持续检测“我的日程”，自动读取当天课程时间，并与应用内已有的课程地点和教师信息合并展示。
- App 只保存登录 Cookie 和课表页面地址，不保存明文账号或密码。
- 首次识别成功后，每次打开 App 都会自动访问已保存的课表地址并刷新课程；登录过期时会显示学校登录页。

## 构建

需要 Android SDK 35、JDK 17 和 Gradle 8.11.1。在本目录运行：

```bash
gradle assembleDebug
```

生成文件：`app/build/outputs/apk/debug/app-debug.apk`。

也可以将本目录推送至 GitHub，仓库自带的 Actions 工作流会生成可下载 APK。
